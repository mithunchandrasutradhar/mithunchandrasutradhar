## 🌟 Eventrosa

### Bangladesh-First Multi-Tenant Event Management SaaS

**Eventrosa** is an event management SaaS platform currently in the specification and architecture phase.

The platform is designed around three primary product pillars:

* RSVP & Guest Management
* Vendor Management
* Supplier Management

Additional platform capabilities are designed around these core areas, including:

* Ticketing
* QR Check-in
* Gift Management
* Raffle Management
* Event Sessions
* Notifications
* Billing
* White-label Support

### Planned Technology Stack

`FastAPI` · `Python` · `Next.js` · `TypeScript` · `PostgreSQL`

### Current Status

**Specification Phase**

The repository currently contains the product vision, technical architecture, roadmap, and engineering specifications. Application implementation has not yet started.
